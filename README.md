# personal-blog

Personal portfolio, academic repository, and technical blog for Ignacio Castillo.

## Stack

- Nuxt 4
- Vue 3 and Vuetify
- TypeScript
- Nuxt Content and Markdown
- Pinia and Vue I18n
- pnpm

## Start here

- Application shell: `app/app.vue`
- Routes: `app/pages/`
- Reusable UI: `app/components/`
- Portfolio data and theme definitions: `utils/`
- Markdown blog content: `content/blog/`
- Shared styles: `app/assets/styles/`

## Project structure

- `app/pages/` — application routes
- `app/components/` — reusable Vue components
- `app/assets/` — styles and bundled assets
- `content/blog/` — markdown-backed technical posts
- `utils/` — portfolio content registry and theme definitions
- `public/` — static public files

## Install and run

```bash
pnpm install
pnpm dev
```

## Commands

- `pnpm build`
- `pnpm dev`
- `pnpm generate`
- `pnpm preview`
- `pnpm lint`
- `pnpm lint:fix`
